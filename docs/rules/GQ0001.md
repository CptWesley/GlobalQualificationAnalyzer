# GQ0001: Use globally qualified type

| Property | Value |
| --- | --- |
| Id | `GQ0001` |
| Category | `Naming` |
| Severity | `Warning` |
| Code fix | Yes |

Message: `Type reference '{0}' must be replaced by '{1}'`

## Explanation

Every reference to a type in code must start with `global::` and spell out the full namespace. A name like `String` or `System.String` depends on which `using` directives are in scope and on which namespace the code lives in: a type or namespace named `System` closer to the code silently changes what the name binds to. `global::System.String` always means the same type.

The rule inspects names that resolve to a type: declarations of fields, properties, parameters, locals and return types, base types, type arguments, `typeof`, casts, `new` expressions, attributes and static member access (`Console.WriteLine()`).

Only the outermost name is reported: `System.Collections.Generic.List<String>` is one diagnostic for the whole name, not one per namespace component. Type arguments that are not globally qualified are reported on their own, so `String` in that name gives a second diagnostic. The replacement of the outer name already qualifies its type arguments, so fixing the outer name fixes both.

The replacement:

- spells out built-in type aliases used as type arguments: `List<int>` becomes `global::System.Collections.Generic.List<global::System.Int32>`, matching [GQ0002](GQ0002.md);
- keeps the `?` on nullable reference and value type arguments, so nullability does not change;
- uses the full attribute type name, including the `Attribute` suffix.

## Rejected

```csharp
using System;
using System.Collections.Generic;

namespace N
{
    class A { }

    [Obsolete]                               // attribute without global:: and without suffix
    class C
    {
        String a;                            // unqualified type
        System.String b;                     // namespace qualified, but not global::
        List<int> c;                         // unqualified generic type
        global::System.Collections.Generic.List<String> d; // unqualified type argument
        A e;                                 // type from the same compilation
        object f = typeof(String);           // typeof
        Int32? g;                            // nullable value type

        void M() => Console.WriteLine();     // static member access
    }

    [global::System.Obsolete]                // globally qualified, but suffix omitted
    class D { }
}
```

## Accepted

```csharp
namespace N
{
    class A { }

    [global::System.ObsoleteAttribute]
    class C
    {
        global::System.String a;
        global::System.String b;
        global::System.Collections.Generic.List<global::System.Int32> c;
        global::System.Collections.Generic.List<global::System.String> d;
        global::N.A e;
        object f = typeof(global::System.String);
        global::System.Int32? g;

        void M() => global::System.Console.WriteLine();
    }

    [global::System.ObsoleteAttribute]
    class D { }
}
```

`object` is still reported by [GQ0002](GQ0002.md); the `using` directives at the top of the rejected sample are reported by [GQ0003](GQ0003.md) and are no longer needed after the rewrite.

## Not reported

- Names that are already globally qualified: `global::System.String`, `global::C`.
- Built-in type aliases such as `int`, `string`, `object`: covered by [GQ0002](GQ0002.md).
- Contextual keywords that cannot be qualified: `var`, `dynamic`, `nint`, `nuint`.
- Type parameters: `T`, `T?`.
- An attribute whose type name has no `Attribute` suffix, when globally qualified: `[global::Marker]` for `class Marker : global::System.Attribute`.
- Names in using directives: covered by [GQ0003](GQ0003.md).
