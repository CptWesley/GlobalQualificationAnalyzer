# GQ0002: Use globally qualified type instead of built-in type alias

| Property | Value |
| --- | --- |
| Id | `GQ0002` |
| Category | `Naming` |
| Severity | `Warning` |
| Code fix | Yes |

Message: `Built-in type alias '{0}' must be replaced by '{1}'`

## Explanation

C# keywords such as `int` and `string` are aliases of types in the `System` namespace. To spell every type the same way as [GQ0001](GQ0001.md) requires, the aliases must be replaced by the globally qualified type they stand for. This applies everywhere in code: declarations, type arguments, arrays, nullable types, casts, `typeof`, `sizeof`, static member access (`string.Empty`) and enum underlying types.

| Alias | Replacement |
| --- | --- |
| `bool` | `global::System.Boolean` |
| `byte` | `global::System.Byte` |
| `sbyte` | `global::System.SByte` |
| `char` | `global::System.Char` |
| `decimal` | `global::System.Decimal` |
| `double` | `global::System.Double` |
| `float` | `global::System.Single` |
| `int` | `global::System.Int32` |
| `uint` | `global::System.UInt32` |
| `long` | `global::System.Int64` |
| `ulong` | `global::System.UInt64` |
| `short` | `global::System.Int16` |
| `ushort` | `global::System.UInt16` |
| `object` | `global::System.Object` |
| `string` | `global::System.String` |

## Rejected

```csharp
#nullable enable

enum E : short { }                                       // enum underlying type

class C
{
    const int X = sizeof(long);                          // declaration and sizeof
    string? a;                                           // nullable reference type
    long? b;                                             // nullable value type
    global::System.Collections.Generic.List<int?[]> c;   // type argument, array, nullable
    object d = string.Empty;                             // static member access
    object e = typeof(long);                             // typeof
    object f = (byte)1;                                  // cast
}
```

## Accepted

```csharp
#nullable enable

enum E : global::System.Int16 { }

class C
{
    const global::System.Int32 X = sizeof(global::System.Int64);
    global::System.String? a;
    global::System.Int64? b;
    global::System.Collections.Generic.List<global::System.Int32?[]> c;
    global::System.Object d = global::System.String.Empty;
    global::System.Object e = typeof(global::System.Int64);
    global::System.Object f = (global::System.Byte)1;
}
```

## Not reported

- `void`, including `void*`: `global::System.Void` is not allowed in C# (CS0673).
- Contextual keywords that are not aliases of a `System` type: `var`, `dynamic`, `nint`, `nuint`.
- Aliases in using directives, such as `using I = int;`: covered by [GQ0004](GQ0004.md).
