# GQ0004: Use globally qualified type instead of built-in type alias in using directive

| Property | Value |
| --- | --- |
| Id | `GQ0004` |
| Category | `Naming` |
| Severity | `Warning` |
| Code fix | Yes |

Message: `Built-in type alias '{0}' in using directive must be replaced by '{1}'`

## Explanation

The using directive equivalent of [GQ0002](GQ0002.md). Built-in type aliases such as `int` and `string` in `using static` and using alias directives must be replaced by the globally qualified type they stand for. This includes aliases used as type arguments, tuple elements, array element types and nullable types. See [GQ0002](GQ0002.md) for the full alias table.

## Rejected

```csharp
using I = int;                                                 // alias
using L = global::System.Collections.Generic.List<long>;       // type argument
using static global::System.Collections.Generic.List<byte>;    // using static
using P = (string, int[], double?);                            // tuple element, array, nullable
```

## Accepted

```csharp
using I = global::System.Int32;
using L = global::System.Collections.Generic.List<global::System.Int64>;
using static global::System.Collections.Generic.List<global::System.Byte>;
using P = (global::System.String, global::System.Int32[], global::System.Double?);
```

## Not reported

- `void`, including `using unsafe P = void*;`: `global::System.Void` is not allowed in C# (CS0673).
- Globally qualified types.
- Aliases outside using directives: covered by [GQ0002](GQ0002.md).
