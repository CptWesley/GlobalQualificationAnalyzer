# GQ0003: Use globally qualified namespace or type in using directive

| Property | Value |
| --- | --- |
| Id | `GQ0003` |
| Category | `Naming` |
| Severity | `Warning` |
| Code fix | Yes |

Message: `Namespace or type '{0}' in using directive must be replaced by '{1}'`

## Explanation

The using directive equivalent of [GQ0001](GQ0001.md). Names in `using`, `global using`, `using static` and using alias directives must start with `global::`. Without it, a directive inside a namespace declaration can bind to a nested namespace or to an alias declared further out, instead of the namespace or type you meant.

Only the outermost name is reported. Type arguments, tuple elements and array element types inside an alias are reported on their own. A name that goes through an alias (`S.Text` with `using S = global::System;`) is rewritten to the namespace or type it resolves to.

## Rejected

```csharp
global using System.IO;                                   // global using
using System;                                             // namespace
using System.Text;                                        // qualified namespace, reported once
using static System.Math;                                 // using static
using T = System.Text;                                    // namespace alias
using S = System.String;                                  // type alias
using L = System.Collections.Generic.List<System.String>; // generic type alias and its type argument
using M = global::System.Collections.Generic.List<System.String>; // type argument only
using P = (System.String, System.Int32[]);                // tuple and array elements

namespace N
{
    using System.Linq;                                    // using inside a namespace declaration
}
```

## Accepted

```csharp
global using global::System.IO;
using global::System;
using global::System.Text;
using static global::System.Math;
using T = global::System.Text;
using S = global::System.String;
using L = global::System.Collections.Generic.List<global::System.String>;
using M = global::System.Collections.Generic.List<global::System.String>;
using P = (global::System.String, global::System.Int32[]);

namespace N
{
    using global::System.Linq;
}
```

## Not reported

- Names that are already globally qualified.
- Built-in type aliases, such as `using I = int;`: covered by [GQ0004](GQ0004.md).
- Contextual keywords that cannot be qualified: `var`, `nint`, `nuint`.
- Names outside using directives: covered by [GQ0001](GQ0001.md).
